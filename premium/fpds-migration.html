FPDS Sunset — What Premium Subscribers Need to Know

FPDS.gov is being decommissioned in favor of SAM.gov contract data. If your pipeline tools, BI dashboards, or competitive-intel scripts still pull from FPDS, you have a migration window measured in months, not years.

Timeline

Feb 24, 2026
FPDS.gov primary site decommissioned. Public-facing FPDS searches return SAM.gov redirects. Read GSA announcement →
FY2026 Q3
FPDS Atom Feed sunset window. Programs still consuming Atom feeds will stop receiving fresh data. Confirm any nightly scrape job that hits the Atom endpoint.
FY2027
Full SAM cutover. SAM.gov Contract Data API becomes the only sanctioned source of federal contract award records. FPDS-vs-SAM field mapping (PDF) →

Is your pipeline at risk?

Three checks. If any answer is yes, you need a migration plan before the next FY rollover.
