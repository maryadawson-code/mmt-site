How it's scored

Each dimension is worth 25 points, scored from direct API queries. Scores combine into a verdict: GO (75+), LEAN GO (55–74), DEVELOP (40–54), LEAN NO-BID (25–39), NO-BID (<25).

  • Incumbent vulnerability — awardee concentration + expiring contracts (USASpending)
  • Budget momentum — obligations volume + budget docs + IT Dashboard programs
  • Legislative tailwind — active bills + CRS reports + committee hearings
  • Research pipeline — completed federal clinical trials + recent PubMed articles
