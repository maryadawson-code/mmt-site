What Ask MMT reads.

Ask MMT answers from the sources below and nothing else. If the answer is not in these systems, it tells you it does not know. Every answer lists which of these it used.

This table is generated at build time from the same source list the assistant runs, so it cannot say one thing while the code does another. Live means queried the moment you ask. Index means the MMT archive, re-indexed on every site build. Conditional means the client is wired but returns nothing until a credential or input it needs exists; those are listed so you know they will not be cited yet. Fallback means a web search of federal sites only, run when the structured sources return nothing; the answer labels those results as leads to verify.

Scope note. Ask MMT pulls federal data by agency. When the APIs return thin results for a question, the answer is labeled "limited API data" so you know to go to the primary source yourself.

When a system does not answer. SAM.gov has a small daily query quota and any API can time out. When that happens the answer says which system was not reached this turn, instead of treating silence as "no such record exists".

Not on this list: the MMT Newswire (ten feeds refreshed every four hours) and the Opportunity Radar. Those are separate surfaces on the site; the assistant does not read them when it answers.

No vendor sites. No sponsored content. No training on your questions. Full practices at missionmeetstech.com/security.
