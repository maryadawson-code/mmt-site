## Standing Rules (agent learns and adds rules here)

Initial rules:
- Do not optimize for consumer health terms
- MMT voice is a differentiator — copy proposals must preserve it
- CSP blocks inline JavaScript — schema in ld+json is data, not code
- Plausible is the only analytics source — do not add Google Analytics
- Site uses a build step (node build.js) — source HTML is at repo root, dist/ is generated
- OG images are generated by build.js — do not manually add og:image paths

## Fix Priority Order (agent reorders based on impact data)

Initial priority (will evolve):
1. Missing meta descriptions (highest indexing impact)
2. Missing/duplicate title tags
3. Missing H1 or multiple H1s
4. Missing canonical tags
5. Missing OG tags
6. Missing JSON-LD schema
7. Missing image alt text
8. Missing sitemap entries
9. Weak internal linking
10. Copy quality (propose only — never auto-apply)
